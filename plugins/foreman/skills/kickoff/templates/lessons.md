# Lições

Regras curtas aprendidas com erros das entregas: uma linha imperativa cada, com os caminhos a que se aplica. O `dev` e o `reviewer` leem antes de cada tarefa.

Antes de escrever uma lição, pergunte se ela pode virar uma checagem automática (teste, helper de teste, regra de lint). O que vira checagem não fica aqui; aqui fica só o que não dá para automatizar.
