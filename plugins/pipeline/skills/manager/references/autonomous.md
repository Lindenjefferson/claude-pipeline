# Autonomous mode

Read when the user turns autonomous mode on (for example before leaving), recorded with `mode autonomous`, or when `status` shows the mode is autonomous. Only then:
- **Heartbeat.** Create a recurring job of this session with `CronCreate` (every 15 minutes, off the :00 and :30 marks) whose prompt is "pipeline heartbeat: run `ledger.py status` and continue the delivery", so a report that arrived without its completion notification never leaves the delivery idle. Create it only when `CronList` shows none. Delete it with `CronDelete` on `mode supervised` and when nothing more can move without the user (the gate READY on the last delivery the user queued, or the delivery stopped with `note --validar`); a resource pause (`pause.md`) is not such a stop. On a resumed session in autonomous mode, check `CronList` and create it again if it is gone; it lives only in this session and expires after 7 days.
- **A resource runs out**: the resource pause of `pause.md`, which keeps the heartbeat.
- Approval 1 becomes the plan reviewer's PASS, or the waiver `status` says; the plan's product decisions and the design page are also `note --validar`.
- Never merge into the default branch, push or deploy; run git through the Bash tool, where the plugin's hook denies merging into and pushing the default branch while the ledger is in autonomous mode. Every `git push` asks the user, who is away, so the work branch is not pushed either. The next delivery starts on a branch stacked on this one (`git switch -c <branch>` from its head, then `start --slug <slug> --archive --base <this branch>` and `mode autonomous` again, since a new ledger starts supervised); its gate takes the base from the ledger.
- When the user is back: `mode supervised`, then run approval 2 (step 7, VALIDAR included) for each delivery, oldest first. For an earlier delivery, switch to its branch and pass `--ledger .superpowers/ledger-<its slug>.jsonl` to `gate.py` and to `ledger.py` (before its command), starting with `mode supervised`; a fix made there is merged into the stacked branch.
