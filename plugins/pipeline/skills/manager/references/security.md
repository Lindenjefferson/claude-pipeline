# Security scan of a sensitive delivery

Read at step 6, when `status` asks for the security scan of a delivery marked `sensitive` (step 0), once the last cycle has closed: the gate waits for it. The scan is the `claude-security` plugin's (a declared dependency): a changes scan of the delivery branch whose every candidate finding goes through a panel of three verifiers. The `reviewer` keeps its security pass in every cycle; this scan replaces no part of it.
- **Run** the `claude-security:claude-security` skill on this branch's changes against the base `status` gives (`--base <base>`), at effort `medium` (`low` while `status` says economy). It needs the Workflow tool and a working `python3`: when either is missing, it says so; that is a block for the user (the kickoff's machine preparation), never a reason to skip the scan. In autonomous mode it waits for the user, standing approval or not: the skill asks a fixed cost question that only their own words answer, never a file or a scheduled prompt, and Remote Control does not show it. Record that as a `note --validar`, which stops the delivery as `autonomous.md` says, send a `PushNotification` that the scan is waiting, and run it on return, then the gate and approval 2.
- **Report**: it writes a `CLAUDE-SECURITY-<timestamp>/` folder at the project root; move it to `.superpowers/reports/<slug>/` and record the run with `add --agent reviewer --task security --report <its CLAUDE-SECURITY-RESULTS.md>`, the severities translated as critical and high to `--critical`, medium to `--important`, low to `--minor`, each with its origin. A later round (`status` asks for it after a FAIL) scans only the fix commits, `--base <the head the failed round recorded>`.
- **Findings**: each Critical or Important one goes to the `dev` as a `fix-N` task, or is deferred with a decision; what the panel set aside as predating the change is `defer`red, never fixed in this delivery unasked. Never copy a finding's text into the quality report, the plan or a commit: the ledger keeps the counts and the report path.
